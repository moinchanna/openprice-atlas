# Security Policy

## Supported Versions

Only the latest release of OpenPrice Atlas is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please do **not** open a public issue. Instead, report it privately.

Please send security reports to the maintainer's email: `moeenchanna@gmail.com` (or open a private security advisory on GitHub).

We endeavor to investigate and address verified security concerns promptly.
